# Markdown 终极极简与进阶自学教程

Markdown 是一种轻量级标记语言，它允许人们使用易读易写的纯文本格式编写文档，并能导出为有效的 HTML、PDF 等多种格式。由于其简洁性、跨平台性以及对排版的极佳支持，Markdown 已成为程序员、撰稿人、学者和笔记爱好者的首选书写工具。

本教程旨在提供一份**全面、详尽且易懂**的 Markdown 指南，从基础入门到高级排版一网打尽。

## 一、基础语法

### 1. 标题

Markdown 支持两种标题标记方法，最常用的是 **Atx 形式**，即在文字前加 `#`。

**语法规则：**

- `#` 的数量代表标题的级别（1 到 6 级）。
- **注意：** `#` 与标题文本之间**必须**加一个空格，这是标准规范。

```markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题
```

> **提示：** 除非是在写长篇书籍，否则日常笔记中建议最多使用到四级标题，以保证排版层次清晰。

### 2. 文本样式

你可以很方便地为文本添加强调效果。

|            |                            |                                  |                  |
| ---------- | -------------------------- | -------------------------------- | ---------------- |
| **样式**   | **语法**                   | **示例源码**                     | **渲染效果**     |
| **斜体**   | 用一个 `*` 或 `_` 包裹     | `*斜体文字*` 或 `_斜体文字_`     | _斜体文字_       |
| **粗体**   | 用两个 `**` 或 `__` 包裹   | `**粗体文字**` 或 `__粗体文字__` | **粗体文字**     |
| **粗斜体** | 用三个 `***` 或 `___` 包裹 | `***粗斜体文字***`               | _**粗斜体文字**_ |
| ~~删除线~~ | 用两个波浪线 `~~` 包裹     | `~~删除线文字~~`                 | ~~删除线文字~~   |

### 3. 列表

#### 无序列表

无序列表使用星号 `*`、加号 `+` 或减号 `-` 作为列表标记（建议统一使用 `-`）。

**源码：**

```markdown
- 苹果
- 香蕉
- 橙子
```

**渲染效果：**

- 苹果
- 香蕉
- 橙子

#### 有序列表

有序列表使用数字加上英文句点 `.`，后面紧跟一个空格。

**源码：**

```markdown
1. 第一步
2. 第二步
3. 第三步
```

**渲染效果：**

1. 第一步
2. 第二步
3. 第三步

> **注意：** 有序列表前面的数字不会影响实际渲染的序列号。例如即使你写 `1. 1. 1.`，渲染出来依然会是 `1. 2. 3.`。但为了源码可读性，建议按顺序书写。

#### 嵌套列表

要创建嵌套列表，只需在子列表项前输入 **4 个空格** 或 **1 个 Tab 键**。

**源码：**

```markdown
- 水果
  - 红色水果
    - 草莓
    - 苹果
  - 黄色水果
    - 香蕉
- 蔬菜
```

**渲染效果：**

- 水果
  - 红色水果
    - 草莓
    - 苹果
  - 黄色水果
    - 香蕉
- 蔬菜

### 4. 区块引用

在段落开头使用 `>` 字符可以创建引用区块。

**源码：**

```markdown
> 这是一个引用区块。
> 知识就是力量。 —— 培根
```

**渲染效果：**

> 这是一个引用区块。知识就是力量。 —— 培根

#### 引用嵌套

引用可以多层嵌套，也可以在引用内使用其他 Markdown 语法（如标题、列表、粗体等）。

**源码：**

```markdown
> ### 嵌套标题
>
> 1. 第一项引用
>    > 这是一个二级嵌套引用
```

**渲染效果：**

> ### 嵌套标题
>
> 1. 第一项引用
>
> > 这是一个二级嵌套引用

### 5. 分割线

你可以在一行中用三个或以上的星号 `*`、减号 `-` 或下划线 `_` 来建立一个分割线。行内不能有其他字符（空格除外）。

**源码：**

```markdown
---

---

---
```

## **渲染效果：**

### 6. 换行与段落

- **段落：** 段落之间通过一个**空行**来分隔。
- **换行（单行内换行）：** 如果你在写诗或需要不分段直接换行，直接回车可能不会生效。
  - 标准做法：在行尾输入**两个以上的空格**，然后回车。
  - 现代有些编辑器也支持直接回车换行，但为了兼容性，尾部双空格是最稳妥的做法。

## 二、链接与媒体

### 1. 超链接

Markdown 支持两种形式的链接：**行内式**和**参考式**。

#### 行内式链接（常用）

语法为 `[链接文字](链接地址 "可选的 Hover 提示文字")`。

**源码：**

```markdown
欢迎访问 [艾斯特的窝窝](https://www.eysnter.cn "eysnter的小站") 我的小站。
```

**渲染效果：** 欢迎访问 [艾斯特的窝窝](https://www.eysnter.cn "null") 搜索引擎。

#### 自动链接

如果你只是想直接展示网址并使其可点击，可以用 `<>` 包裹。

**源码：**

```markdown
我的邮箱是 <czk246310@gmail.com>
或者访问网址 [https://markdown.com.cn](https://markdown.com.cn)
```

**渲染效果：** 我的邮箱是 [czk246310@gmail.com](mailto:czk246310@gmail.com "null") 或者访问网址 [ https://markdown.com.cn ](https://markdown.com.cn "null")

### 2. 图片引入

图片的语法与超链接非常相似，只需在前面多加一个感叹号 `!`： `![替代文本](图片链接 "可选的图片标题")`

**源码：**

```markdown
![Markdown 标志](https://markdown-here.com/img/icon256.png "Markdown Logo")
```

**渲染效果：**

> **关于图片尺寸控制：** 原生 Markdown 不支持控制图片大小。如果需要调整图片宽高，建议使用原生的 HTML `<img>` 标签，例如： `<img src="https://markdown-here.com/img/icon256.png" width="100" height="100" alt="Markdown 标志" />`

## 三、代码排版

Markdown 对程序员极其友好，提供了行内代码和代码块两种排版方式。

### 1. 行内代码

使用反引号 `（通常在键盘 Esc 键下方）包裹代码。

**源码：**

```markdown
在 Java 中，我们常使用 `System.out.println()` 来输出内容。
```

**渲染效果：** 在 Java 中，我们常使用 `System.out.println()` 来输出内容。

### 2. 代码块

使用三个反引号 ` ``` ` 包裹一段代码。你可以在第一组反引号后面指定**编程语言的名称**，以实现代码高亮。

**源码：**

````
```python
# 这是一个 Python 代码示例
def greet(name):
    print(f"Hello, {name}!")

greet("Markdown")
````

````

**渲染效果：**
```python
# 这是一个 Python 代码示例
def greet(name):
    print(f"Hello, {name}!")

greet("Markdown")
````

## 四、高级拓展语法 (GFM 及常见拓展)

这些语法并非所有 Markdown 解析器都默认支持，但绝大多数现代平台（如 GitHub、Notion、Obsidian、Typora）都已完美支持。

### 1. 表格

表格使用竖线 `|` 分隔不同的列，并使用减号 `-` 所在的一行来分隔表头与内容。

**源码：**

```markdown
| 姓名 | 年龄 |     职业 |
| :--- | :--: | -------: |
| 张三 |  25  |   工程师 |
| 李四 |  30  |   设计师 |
| 王五 |  28  | 产品经理 |
```

**渲染效果：**

|          |          |          |
| -------- | -------- | -------- |
| **姓名** | **年龄** | **职业** |
| 张三     | 25       | 工程师   |
| 李四     | 30       | 设计师   |
| 王五     | 28       | 产品经理 |

**对齐规则说明：**

- `:---` 或 `---` 表示**左对齐**。
- `:---:` 表示**居中对齐**。
- `---:` 表示**右对齐**。

### 2. 任务列表

任务列表常用于待办事项（To-Do List）。

**源码：**

```markdown
- [x] 完成 Markdown 基础语法学习
- [ ] 掌握 Markdown 高级拓展语法
- [ ] 撰写一篇技术博客
```

**渲染效果：**

- [x] 完成 Markdown 基础语法学习
- [ ] 掌握 Markdown 高级拓展语法
- [ ] 撰写一篇技术博客

> **提示：** 英文方括号内，大写或小写的 `x` 代表已完成（选中），空格代表未完成。

### 3. 数学公式 (LaTeX)

许多现代编辑器（如 Typora、Notion 等）支持使用 LaTeX 语法渲染精美的数学公式。

- **行内公式：** 使用单个 `$` 包裹。
- **独行（块级）公式：** 使用两个 `$$` 包裹。

**源码：**

```
当 $a \ne 0$ 时，一元二次方程 $ax^2 + bx + c = 0$ 的求根公式为：

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
```

**渲染效果：** 当 $a \ne 0$ 时，一元二次方程 $ax^2 + bx + c = 0$ 的求根公式为：

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

### 4. 脚注

脚注用于为文中的某些词汇或句子添加注释说明，通常会渲染在文章的末尾。

**源码：**

```markdown
这是一个使用 Markdown 脚注的例子[^1]。

[^1]: 这是脚注的具体内容，它通常会出现在文档的最底部。
```

**渲染效果：** 这是一个使用 Markdown 脚注的例子[^1](这是脚注的具体内容，它通常会出现在文档的最底部。 "null")。

### 5. Emoji 表情

在许多支持 GFM（GitHub Flavored Markdown）的平台上，你可以使用冒号包裹特定字符来输入表情。

**源码：**

```markdown
今天的心情非常棒！ :smile: :tada: :pizza:
```

**渲染效果：** 今天的心情非常棒！ 😄 🎉 🍕

> **小技巧：** 现代操作系统（Windows：`Win + .`，macOS：`Ctrl + Cmd + Space`）都自带 Emoji 输入法，直接在 Markdown 里输入 Emoji 字符在所有平台上都 100% 兼容。

## 五、HTML 混排与特殊字符转义

### 1. 嵌入原生 HTML

Markdown 兼容 HTML 语法。如果 Markdown 的原生语法无法满足你的排版需求，你可以直接在文档里写 HTML 代码。

**常用场景：**

- 居中文字或图片：`<center>这段文字会居中显示</center>`
- 改变字体颜色和大小：`<font color="red" size="4">红色的四号字</font>`
- 换行：使用 `<br>`

### 2. 特殊字符转义

如果你想在 Markdown 中直接输出具有特殊含义的标记字符（例如想在文本里直接显示 `*` 星号，而不是让它变成斜体），可以使用**反斜杠 `\`** 进行转义。

**支持转义的字符：**

```markdown
\ 反斜线
` 反引号

- 星号
  \_ 下划线
  {} 花括号
  [] 方括号
  () 圆括号

# 井号

- 加号

* 减号
  . 英文句点
  ! 感叹号
```

**示例：** `\*这段文字两侧有真实的星号，不会变成斜体\*`

渲染效果：_这段文字两侧有真实的星号，不会变成斜体_

## 六、Markdown 写作最佳实践

1. **坚持空格规范：** - 标题 `#` 后面一定要加空格。
   - 列表 `-` 或 `1.` 后面一定要加空格。
   - 中英文混排时，在中文和英文/数字/链接之间手动加一个空格（例如：“我今天学习了 Markdown 语法”），这样能让排版看起来极度舒适。

2. **源码可读性第一：** 不要在一行里堆叠过多的 HTML 标签，尽量使用纯粹的 Markdown 语法。
3. **选择合适的编辑器：**
   - **Typora**：极致的双向实时预览体验（所见即所得）。
   - **Obsidian**：强大的个人知识库管理工具，基于双链和 Markdown。
   - **VS Code**：配合 `Markdown All in One` 插件，适合程序员写作。
   - **Notion / 语雀**：优秀的云端协作与笔记软件，天然支持 Markdown 快捷键输入。
