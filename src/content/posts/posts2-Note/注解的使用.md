# **注解的使用**

| 注解                   | 所属框架        | 作用                                                               | 使用位置          | 来源 / 触发方式         | 示例 URL / 代码                                                                      | 是否可省略                    |
| -------------------- | ----------- | ---------------------------------------------------------------- | ------------- | ----------------- | -------------------------------------------------------------------------------- | ------------------------ |
| `@RestController`    | Spring Boot | 声明该类为 **RESTful 控制器**，返回 JSON（= `@Controller` + `@ResponseBody`） | **类上**        | —                 | `@RestController`                                                                | ❌ 不可省略                   |
| `@RequestMapping`    | Spring MVC  | 定义 **URL 基础路径前缀**                                                | 类或方法          | —                 | `@RequestMapping("/depts")`                                                      | ❌（若需统一路径）                |
| `@GetMapping`        | Spring MVC  | 映射 **HTTP GET 请求**                                               | 方法            | 访问对应 URL 时触发      | `@GetMapping("/{id}")` → `GET /depts/5`                                          | ❌                        |
| `@PostMapping`       | Spring MVC  | 映射 **HTTP POST 请求**（通常用于新增）                                      | 方法            | 发送 POST 请求        | `@PostMapping` → `POST /depts`                                                   | ❌                        |
| `@PutMapping`        | Spring MVC  | 映射 **HTTP PUT 请求**（通常用于更新）                                       | 方法            | 发送 PUT 请求         | `@PutMapping` → `PUT /depts`                                                     | ❌                        |
| `@DeleteMapping`     | Spring MVC  | 映射 **HTTP DELETE 请求**（用于删除）                                      | 方法            | 发送 DELETE 请求      | `@DeleteMapping` → `DELETE /depts?id=5`                                          | ❌                        |
| `@ 注解              ` | 所属框架        | 作用                                                               | 使用位置          | 来源 / 触发方式         | 示例 URL / 代码                                                                      | 是否可省略                    |
| `@RequestParam`      | Spring MVC  | **绑定 URL 查询参数**（`?key=value`）                                    | 方法参数          | 问号后的参数            | `?id=5` → `@RequestParam Integer id` 或直接 `Integer id`                            | ✅ **可省略**（参数名一致时）        |
| `@RequestBody`       | Spring MVC  | 将 **请求体 JSON 数据** 自动转为 Java 对象                                   | 方法参数          | 请求体（Body）传 JSON   | `{"id":5,"name":"技术部"}` → `@RequestBody Dept dept`                               | ❌ **不可省略**               |
| `@Autowired`         | Spring      | **自动注入** Bean（依赖注入）                                              | 字段 / 构造器 / 方法 | Spring 容器管理的 Bean | `@Autowired private DeptService deptService;`                                    | ✅（可用构造器注入替代）             |
| `@Service`           | Spring      | 标记 **业务逻辑层组件**，被 Spring 扫描管理                                     | **类上**        | —                 | `@Service public class DeptServiceImpl`                                          | ❌（若需被扫描）                 |
| `@Mapper`            | MyBatis     | 标记 **MyBatis 数据访问接口**                                            | **接口上**       | —                 | `@Mapper public interface DeptMapper`                                            | ❌（或用 `@MapperScan` 批量扫描） |
| `@Select`            | MyBatis     | 在接口中直接写 **SQL 查询语句**                                             | **方法上**       | 调用该方法时执行 SQL      | `@Select("SELECT * FROM dept") List<Dept> findAll();`                            | ❌                        |
| `@Delete`            | MyBatis     | 在接口中写 **SQL 删除语句**                                               | 方法            | 调用时执行 DELETE      | `@Delete("DELETE FROM dept WHERE id=#{id}") void deleteById(Integer id);`        | ❌                        |
| `@Update`            | MyBatis     | 在接口中写 **SQL 更新语句**                                               | 方法            | 调用时执行 UPDATE      | `@Update("UPDATE dept SET name=#{name} WHERE id=#{id}") void update(Dept dept);` | ❌                        |
| `@Slf4j`             | Lombok      | 自动生成 **日志对象 `log`**（类型：`Logger`）                                 | **类上**        | 编译时生成代码           | `log.info("查询部门");`                                                              | ❌（需 Lombok 支持）           |
